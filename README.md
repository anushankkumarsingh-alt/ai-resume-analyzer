🤖 AI Resume Analyzer

A beginner-friendly Python tool that analyzes resume text, detects common technical skills and resume sections, calculates a basic score, and provides improvement suggestions.

✨ Features

- 🔎 Detect common technical skills
- 📂 Check for important resume sections
- 📊 Calculate a basic resume score
- 💡 Provide improvement suggestions
- 📝 Count resume words
- ⚠️ Identify potentially missing sections

🛠️ Technologies & Concepts

- Python
- String processing
- Lists
- Dictionaries
- Loops
- Conditional statements
- User input
- Basic text analysis
- Input validation

🚀 How It Works

1. Paste your resume text into the program.
2. The program analyzes the text.
3. It checks for common technical skills.
4. It checks for important resume sections.
5. It calculates a basic score.
6. It provides suggestions for improvement.

▶️ How to Run

Make sure Python is installed.

python resume_analyzer.py

📊 Scoring

The current scoring system is a simple educational scoring system, not a professional ATS score.

The score considers:

- Resume length
- Number of detected technical skills
- Number of detected resume sections

The maximum score is 100.
